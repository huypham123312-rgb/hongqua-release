# Hong Qua — bộ cài

Kho này chỉ chứa **bộ cài** của app Hong Qua (ghi phim, tải Bilibili, thư viện xem offline, dịch + lồng tiếng qua VoxTrend). Mã nguồn không nằm ở đây.

## Cài lần đầu
1. Vào [Releases](../../releases/latest), tải **HongQua-Setup.exe**.
2. Chạy file. Windows cảnh báo → **More info → Run anyway**.
3. App tự cài vào máy, tạo biểu tượng **Hong Qua** ngoài Desktop và mở lên. Hướng dẫn chi tiết: tab **Hướng dẫn** trong app.

## Cập nhật
App tự kiểm tra bản mới khi mở. Có bản mới thì hiện dải **«Cập nhật ngay»** ở trên cùng: bấm là app tự tải, tự cài đè rồi mở lại. Cài đặt, đăng nhập và phim đã lưu giữ nguyên.
